시멘틱 태그란?

시멘틱 태그는 HTML5에서 도입된 태그로, 문서의 구조와 의미를 명확하게 표현합니다.

HTML5 시멘틱 태그의 장점

2024년 1월 15일 작성

1. 접근성 향상

스크린 리더와 같은 보조 기술이 문서 구조를 더 잘 이해할 수 있습니다.

2. SEO 개선

검색 엔진이 콘텐츠를 더 정확하게 분석하고 인덱싱할 수 있습니다.

💡 팁

시멘틱 태그를 사용하면 CSS 스타일링도 더 직관적이고 유지보수가 쉬워집니다.

주요 시멘틱 태그들

2024년 1월 20일 작성

header - 페이지나 섹션의 헤더
nav - 네비게이션 링크
main - 문서의 주요 콘텐츠
article - 독립적인 글이나 콘텐츠
section - 문서의 구역
aside - 부가적인 정보
footer - 페이지나 섹션의 푸터
